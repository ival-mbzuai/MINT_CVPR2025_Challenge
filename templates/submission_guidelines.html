When submitting your test results, please adhere to the following instructions.

The results you submit must be in a JSON file. All results in the JSON file, inside the keys "oe" and "mcq" should be stored as a list, with each element in the list being a dictionary. For open-ended(oe) and mcq QAs, they follow this format: 


  {
    "oe": [
      {
        "unique_id": 2747,
        "language": "english",
        "video_id": "vid_29.mp4",
        "question_format": "Open Ended",
        "video_category": "Life Record",
        "duration": "short",
        "Q": "How many unique people are shown to be present in the video?",
        "A": "There are two unique people shown in the video."
      }
    ],
    "mcq": [
      {
        "unique_id": 4760,
        "language": "english",
        "video_id": "vid_1.mp4",
        "question_format": "MCQ",
        "video_category": "Sports Competition",
        "duration": "medium",
        "Q": "Where is the location of the race as shown in the video?",
        "A": "D",
        "options": [
            "Sea side",
            "City",
            "Desert",
            "Mountain"
        ]
      }
    ]
  }

The evaluation process may take up to an hour. If there is a high volume of user submissions, it might take longer. Please be patient and monitor the progress in the 'My Submissions' section.
